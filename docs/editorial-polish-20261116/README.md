## 変更
- アシスタントとスタイリストの募集要項を共通カードに統一。スタイリストの条件を常時表示。
- ヘッダーを「採用について相談する」に変更し、募集条件・教育へのリンクを整理。
- 募集対象 → 給与・働き方 → サロン → カリキュラム・入社後の流れ → 作品 → スタッフ → 理念 → 任意の診断 → 相談、の順に配置。
- 同じ内容を繰り返す表現を整理。給与、カリキュラムの人数、待遇、既存の写真・相談先は維持。
- 本文、注記、見出し、写真の比率と余白を調整。スマートフォンでは冒頭の写真を相談ボタンの前に配置。
- 診断を開閉式に変更。固定相談ボタンは冒頭・末尾の相談ボタンとの重複表示を抑制。
