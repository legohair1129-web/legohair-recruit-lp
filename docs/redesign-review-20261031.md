# LEGOHAIR 中途採用LP｜第2稿 プレビュー確認資料

## 今回のデザイン修正

メインコピーを「人を素敵にできる私になる。」へ変更。提示いただいたコピー例はそのまま使用していません。説明文や見出しから不自然な読点・句点を整理し、短くても意味がつながる日本語に整えました。既存診断の質問・選択肢・結果文と、出典のある本人の発言は改変していません。

- 鮮やかなベタ塗りから、淡いローズ、ブルーグレー、ラベンダー、セージ、バターイエローの配色へ。
- 絵の具のにじみを思わせる透過グラデーションと、PCでは輪郭にゆらぎを加えた色面。
- 写真の下に薄紙、透ける色面、少しずらした台紙を重ね、柔らかな影で奥行きを追加。
- 目立つ丸ステッカー・太い下線を控え、メイン見出しとセクション見出しを明朝体へ変更。
- 人物写真そのものは生成・加工せず、CSSによるレイヤー・トリミングで表現。
- スマホでは色面のフィルターを省略し、静的グラデーションで軽量化。既存のreduced-motion対応を維持。

第2稿の検証：375 / 390 / 430 / 768 / 1440pxで横はみ出しなし。390pxで全8セクションの見え方、メニュー、診断5問から結果までを確認。PCではCTAと人物写真、キャプションの位置を調整。ビルド・JS構文・差分チェック、診断1,024通りの検証が通過。

## LP全体の構成

中途アシスタント・第二新卒を中心に、8画面の淡いエディトリアル・コラージュ構成へ刷新。

## リンクと計測

公式HPと最新新卒コードで、見学と応募が同じGoogle Formに統一されていることを確認。LINEは https://lin.ee/7dPFevn 。外部Google Formの直接HTTP確認は401のため、受付完了までの動作確認は未実施。LINEの利用とフォーム受付の最終確認は公開前の運用確認として残す。

既存中途LPには本番ホスト限定のMeta Pixelがあり、同意UIは確認できなかった。既存のLINEクリックの`Lead`は応募完了を意味しない。

新プレビューは広告ピクセルを読み込まず、Cookieや個人情報を保存・送信しない。`legohair:analytics`のローカルイベントと、明示的な同意済みアダプターへの接続口を用意。広告流入はパラメーターの有無のみ判定し、パラメーター値や診断回答を記録しない。

| イベント | 実装 |
|---|---|
| landing_view / ad_landing_view | LP表示。広告パラメーターの有無のみ |
| diagnosis_start | 診断開始・やり直し |
| diagnosis_complete | 全5問回答。回答・結果タイプは送らない |
| salon_tour_click | Google Formを開くクリック |
| line_consultation_click | LINE窓口へのクリック |
| official_recruit_click | 公式採用HP等へのクリック、placementで区別 |
| 応募完了 | 未実装。外部フォーム側の成功通知を確認できないため、クリックを応募完了として扱わない |

公開前に既存計測の同意処理とアダプターを接続する必要がある。これはプレビューの見た目・操作には影響しない。
